# Guia de Uso - Response Live

## Visão Geral

Response Live é uma plataforma de conexão entre pacientes e cuidadores de saúde com chat em tempo real, pagamentos simulados e gerenciamento financeiro.

## Para Pacientes

### 1. Login/Cadastro
1. Abra o app
2. Clique em "Não tem conta?" para se registrar
3. Preencha seus dados (Nome, Email, Senha)
4. Confirme o cadastro

### 2. Solicitar Atendimento
1. Na tela inicial, clique em "Solicitar Novo Atendimento"
2. Preencha:
   - **Tipo de Cuidado**: escolha (Higiene, Medicação, Companhia, etc)
   - **Data e Hora**: selecione quando precisa
   - **Duração**: quanto tempo durará o atendimento
   - **Local**: endereço completo
   - **Valor**: preço que oferece (R$ 50 - R$ 500)
   - **Forma de Pagamento**: Pix, Cartão ou Dinheiro
   - **Observações**: informações especiais para o cuidador

3. Clique em "Solicitar Atendimento"
4. O sistema buscará cuidadores interessados

### 3. Revisar Candidatos
1. Quando cuidadores se candidatarem, você verá na página de detalhes
2. Clique em cada candidato para ver:
   - Avaliação e estrelas
   - Bio e especialidades
   - Experiência
   - Total de atendimentos

3. Clique em **"Contratar Este Cuidador"** para aprovar
4. O chat será liberado para comunicação

### 4. Chat em Tempo Real
1. Clique no aba "Chat" na barra inferior
2. Selecione a conversa
3. **As mensagens aparecem em tempo real**
4. Você pode:
   - Enviar mensagens de texto
   - Ver quando o cuidador vê a mensagem (check azul)
   - Sair do chat a qualquer momento

### 5. Realizar Pagamento
1. Quando o atendimento terminar, clique "Ir para Pagamento"
2. Escolha a forma:

   **PIX:**
   - Gera um QR Code simulado
   - Ou copia o código Pix
   - Clica "Confirmar Pagamento"

   **CARTÃO:**
   - Preenche: Nome, Número, Validade, CVV
   - Clica "Pagar"
   - Simula processamento

   **DINHEIRO:**
   - Confirma que pagará presencialmente
   - O cuidador receberá a taxa pendente

3. Após confirmação → Pagamento realizado com sucesso

### 6. Avaliar Cuidador
1. Após o atendimento ficar "Concluído"
2. Clique "Avaliar Agora"
3. Escolha 1-5 estrelas
4. Deixe um comentário (opcional)
5. Envie a avaliação

### 7. Histórico e Notificações
- **Histórico**: veja todos seus atendimentos
- **Avisos**: receba notificações de atualizações
- **Perfil**: edite seus dados

## Para Cuidadores

### 1. Login/Cadastro como Cuidador
1. Faça cadastro normal
2. Complete perfil como **Cuidador**:
   - CPF
   - Bio/Experiência
   - Anos de experiência
   - Especialidades
   - Chave Pix (para receber)

### 2. Procurar Atendimentos
1. Na tela inicial, veja solicitações disponíveis
2. Clique em uma que te interessa
3. Clique "Tenho Interesse" ou "Aceitar"
4. Aguarde o paciente aprovação

### 3. Chat com Paciente
1. Após aprovado, converse com paciente pelo chat
2. As mensagens são **em tempo real**
3. Confirme os detalhes do atendimento

### 4. Monitoramento Durante Atendimento
1. Quando o atendimento começar, clique "Iniciar Monitoramento"
2. Tire fotos periódicas para registro
3. O paciente vê as fotos em tempo real

### 5. Carteira e Saldo
1. Clique na aba "Carteira" (ícone 💰)
2. Veja seu saldo disponível
3. Veja histórico de:
   - Recebimentos
   - Saques
   - Transações pendentes

### 6. Solicitar Saque
1. Na Carteira, clique "Solicitar Saque"
2. Digite o valor (mínimo R$ 10)
3. Escolha:
   - **Pix**: com chave Pix
   - **Conta Bancária**: com dados da conta
4. Clique "Solicitar Saque"
5. Status muda para "Em processamento" → "Concluído"

### 7. Avaliar Paciente
1. Após atendimento finalizado
2. Clique "Como foi o paciente?"
3. Avalie de 1-5 estrelas
4. Deixe comentário
5. Envie

## Instalação como App

### Android
1. Abra no Chrome
2. Aguarde o popup "Instalar"
3. Clique em "Instalar"
4. Pronto! O app está na tela inicial

### iPhone/iPad
1. Abra no Safari
2. Clique em compartilhar (↑)
3. Selecione "Adicionar à tela inicial"
4. Confirme
5. Pronto!

## Recursos Offline

- Você pode visualizar dados em cache
- Sem internet = sem chat/pagamentos/atualizações
- Sincroniza automaticamente quando conecta

## Dicas

- **Chat**: as mensagens chegam em tempo real
- **Notificações**: ative para não perder atualizações
- **Avaliações**: ajudam a construir credibilidade
- **Pix**: é simulado para demonstração
- **Saque**: também é simulado para teste

## Troubleshooting

### Cuidador não aparece na lista
- Ele pode estar offline ou não ter interesse
- Tente buscar outro

### Chat não atualiza
- Recarregue a página
- Verifique sua conexão
- O chat só funciona se o atendimento está "Confirmado"

### Pagamento não funciona
- Verifique se selecionou a forma de pagamento
- Se Pix/Cartão → preencha os dados corretamente
- Se Dinheiro → confirme pagamento presencial

### Não consigo descarregar o app
- Verifique se está em um navegador compatível
- Aguarde o popup de instalação
- Recarregue a página se necessário
